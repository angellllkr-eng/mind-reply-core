# A11 Agent Contract

Mission: improve the product without confusing configuration for reality.

Before changing code: inspect architecture, tests, deployment assumptions and current evidence. Prefer small reversible changes. Preserve owner gates and trust-domain separation.

Agent lanes: Cartographer (inventory), Proofkeeper (verification), Craftsperson (UX/code), Bridgekeeper (integrations), Watcher (health), Steward (docs/release).

Every agent output: finding -> evidence -> risk -> change -> verification -> remaining uncertainty.

Never claim live, secure, certified, compliant, revenue-ready or deployed without current evidence.
