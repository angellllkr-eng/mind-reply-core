# NOVA Digital Hall — Commercial UX Benchmark

## Product target

NOVA Digital Hall is being shaped as a premium commercial gaming-hall experience, using established UK and Bulgarian operator experiences as **UX reference points**, including Sky Vegas, Betfred, Winbet, AlphaWin and Palms Bet.

This is a product-pattern benchmark, not a request to copy competitor branding, artwork, proprietary copy or protected assets.

## Experience patterns to carry into NOVA

- Strong first-screen discovery with a clear featured/promotional area.
- Persistent, simple primary navigation.
- Game discovery rails and category browsing.
- Slots, live/table experiences, jackpots and new/trending discovery.
- Search and useful filters.
- Promotions and rewards/VIP surfaces.
- Personalised/recent/favourite game areas where supported.
- Account area with clear balance/account states when those capabilities are actually implemented.
- Mobile-first interaction patterns and fast game discovery.
- Clear help, safer-gaming and legal/support access.
- Market-aware content and language rather than one generic global experience.

## NOVA implementation boundary

The current repository contains a frontend Digital Hall foundation with mock/demo content. Commercial-grade UX is the target; real-money wagering, deposits, withdrawals, wallet operation, regulated game sessions and market activation remain separately gated by verified legal, licensing, supplier, payment, technical and operational evidence.

## Design direction

Premium, modern, high-contrast and easy to understand. Use original NOVA visual language and assets. Reproduce useful interaction patterns and information architecture only at the level of common product conventions.

## Deployment direction

Canonical deployment path:

**GitHub → ResellerPro → Cloudflare → verified environment**

Vercel is legacy and is not the current deployment target.

## Truth rule

A benchmark, UI component, mock integration or planning document is not evidence that a regulated capability is licensed, approved, connected or live.
