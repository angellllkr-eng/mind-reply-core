# NOVA Public Claims Register

Status: CONTROLLED COPY STANDARD

Every material public claim must have a source owner and evidence date.

## Allowed claim pattern

CLAIM → SOURCE → DATE → SCOPE → EXPIRY/REVIEW → OWNER

## Prohibited shortcut

Do not write 'licensed', 'certified', 'approved', 'secure', 'bank-grade', 'fully compliant', 'regulated', 'live', 'real-money' or equivalent language merely because:
- a supplier says it;
- a competitor says it;
- a mock screen displays it;
- a generated document says it;
- an old planning document says it;
- a test environment contains it.

## Demo state

NOVA may describe itself as a Digital Hall/demo experience while it is in DEMO or STAGING_SYNTHETIC. Synthetic balances, winners, jackpots and live-table states must remain clearly illustrative.

## Release discipline

When a claim changes, the relevant source, UI copy, legal text and evidence register must be reviewed together.
