# Phone-First Language

This branch should read like a service a person can use from a phone, not like a generic SaaS demo.

## Terms for this branch

| Term | Meaning |
|---|---|
| **Thumb Lane** | the primary mobile action path |
| **Pocket Proof** | lightweight evidence that an action worked |
| **Soft Confirm** | a clear confirmation step |
| **Quiet Exit** | a safe way to back out of an action |
| **Human Signal** | something a real person can verify or approve |
| **Touch Path** | the shortest route from intent to result |

## Writing rules

- Prefer short labels and clear verbs.
- Keep primary actions above the fold on phones.
- Avoid making the user read a long explanation before acting.
- Use empty states that tell the user what to do next.
- Do not hide success or failure behind a spinner alone.
