# NOVA — Legacy Plan Reconciliation

Updated: 2026-09-22

The repository contains historical planning documents written before the deployment and evidence policy was corrected. They are retained for provenance, but they are not authoritative where they conflict with current policy.

## Authoritative current state

- Canonical source: GitHub repository main branch.
- Deployment direction: GitHub → ResellerPro → Cloudflare → verified environment.
- Current product: free-play/demo Digital Hall.
- Real-money activation: separately gated and not evidenced.
- Licensing: unverified in this repository.
- ResellerPro deployment: unverified in this repository.
- Cloudflare production: unverified in this repository.

## Historical statements that must not be treated as current facts

Any document claiming that NOVA is already dual-licensed, that applications were filed, that domains are live, that Vercel is the active host, that provider contracts are signed, that KYC/AML is live, or that compliance controls are implemented is planning/history unless a corresponding evidence artifact exists.

Exact regulatory thresholds, session durations, deposit caps, fees, helpline numbers, provider approval status and licence numbers must be sourced from the applicable regulator, contract or counsel-approved configuration before publication or implementation.

## Source-of-truth order

1. Current compliance evidence.
2. Current deployment evidence.
3. Current code and automated test evidence.
4. Signed commercial/provider evidence.
5. Counsel/regulator-confirmed requirements.
6. Historical planning documents.

This prevents stale planning prose from becoming a false production claim.
